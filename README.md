# 1. 프로젝트 제목

```text
2023~2025년 삼성전자 주가 트렌드 분석
```

---

## 2. 프로젝트 소개

```text
본 프로젝트는 2023년부터 2025년까지의 삼성전자(005930.KS) 주가 데이터를 분석하여 기간별 주가 추세와 변동성을 확인하는 것을 목적으로 한다.

20일 이동평균, 일별 수익률, 월별 수익률, 20일 이동 변동성 등의 시계열 분석 기법을 활용하여 주가가 크게 상승하거나 하락한 시점과 변동성이 높았던 기간을 분석하였다.
```

---

## 3. 분석 주제 및 선정 이유

```text
삼성전자는 국내 대표적인 기업으로 주가 데이터를 비교적 쉽게 확보할 수 있어 분석 대상으로 선정하였다.

2023~2025년 동안 삼성전자 주가가 어떤 추세를 보였는지, 어느 시기에 큰 폭의 상승과 하락이 나타났는지, 그리고 변동성이 높은 시점은 언제였는지 확인하고자 하였다.
```

---

## 4. 분석 질문 (3개 이상 필수)

```text
Q1. 2023~2025년 삼성전자 주가는 전체적으로 어떤 추세를 보였는가?
Q2. 분석 기간 중 주가가 크게 상승하거나 하락한 시점은 언제이며, 변동 폭은 어느 정도였는가?
Q3. 월별 수익률을 비교했을 때 기간별로 어떤 차이가 나타났는가?
Q4. 삼성전자 주가의 변동성이 가장 높았던 시점은 언제인가?
```

---

## 5. 데이터 설명

### 5-1. 데이터 출처

```text
Yahoo Finance의 삼성전자(005930.KS) Historical Data를 이용하였다.

출처:
https://finance.yahoo.com/quote/005930.KS/history/
```

Yahoo Finance에서는 삼성전자 `005930.KS`의 일별 과거 주가 데이터와 Open, High, Low, Close, Adj Close, Volume 등의 정보를 제공한다.

### 5-2. 데이터 기간

```text
2023-01-02 ~ 2025-12-30
```

분석을 위해 2023-01-01부터 2025-12-31까지의 데이터를 요청했으며, 실제 거래일 기준 데이터는 2023-01-02부터 2025-12-30까지 수집되었다.

### 5-3. 데이터 포인트 수

```text
총 730개
```

### 5-4. 주요 컬럼 설명

```text
| 컬럼명 | 설명 |
|--------|------|
| Date | 거래 날짜 |
| Open | 해당 거래일의 시가 |
| High | 해당 거래일의 최고가 |
| Low | 해당 거래일의 최저가 |
| Close | 해당 거래일의 종가 |
| Adj Close | 배당 및 분할 등을 반영한 수정 종가 |
| Volume | 해당 거래일의 거래량 |
```

### 5-5. 라이선스 / 사용 주의사항

```text
본 데이터는 Yahoo Finance에서 수집한 주가 데이터이다.

Yahoo Finance의 데이터 이용 조건 및 서비스 약관을 확인하여 사용해야 하며, 본 프로젝트에서는 데이터 출처를 명시하였다. 데이터의 상업적 이용 또는 재배포가 필요한 경우 Yahoo Finance의 최신 이용약관을 별도로 확인해야 한다.
```

## 7. 실행 방법

### 7-1. 환경 설정

```bash
pip install -r requirements.txt
```

또는 필요한 라이브러리를 직접 설치할 수 있다.

```bash
pip install pandas matplotlib yfinance
```

### 7-2. 분석 실행 순서

```text
1. 프로젝트 폴더로 이동한다.
2. requirements.txt를 이용하여 필요한 라이브러리를 설치한다.
3. analysis.py를 실행한다.
4. Yahoo Finance에서 삼성전자 주가 데이터를 수집한다.
5. 분석 결과가 터미널에 출력된다.
6. 분석에 사용된 CSV 파일이 data/ 폴더에 저장된다.
7. 생성된 그래프가 images/ 폴더에 저장된다.
8. REPORT.md에서 분석 결과와 인사이트를 확인한다.
```

실행 명령어:

```bash
python analysis.py
```

## 9. 적용한 시계열 분석 기법 (2가지 이상 필수)

```text
1. 20일 이동평균 - 단기적인 주가 변동을 완화하고 전체적인 주가 추세를 확인하기 위해 사용하였다.
2. 일별 수익률 - 하루 동안 주가가 얼마나 상승하거나 하락했는지 확인하기 위해 사용하였다.
3. 월별 수익률 - 월별 주가 변화율을 비교하여 기간별 상승 및 하락 패턴을 확인하기 위해 사용하였다.
4. 20일 이동 변동성 - 최근 20거래일의 일별 수익률 표준편차를 계산하여 변동성이 높은 기간을 확인하기 위해 사용하였다.
```

## 10. 결측치 / 이상치 처리 방법

```text
- 결측치: 전체 데이터의 결측치를 확인한 결과 결측치는 0개였으므로 별도의 결측치 대체 또는 삭제를 수행하지 않았다.
- 이상치: 주가 분석에서 큰 상승이나 하락 자체가 중요한 분석 대상이므로 임의로 이상치를 삭제하지 않았다. 대신 일별 수익률과 변동성을 이용하여 큰 변동이 나타난 시점을 분석하였다.
```

```text
- 인사이트 1: 2024년 8월과 9월의 월별 수익률은 각각 -11.44%, -17.23%로 큰 폭의 하락이 나타났다.
```

## 13. 결론 및 한계점

### 13-1. 결론

```text
2023~2025년 삼성전자 주가는 기간에 따라 상승과 하락의 폭이 크게 달라지는 모습을 보였다. 특히 2024년 하반기에는 큰 폭의 월간 하락이 나타났으며, 2025년 하반기에는 큰 폭의 상승과 하락이 반복되었다.

이동평균, 수익률, 월별 집계, 이동 변동성을 함께 활용함으로써 단순한 주가 그래프보다 시기별 주가 변화와 변동성을 구체적으로 확인할 수 있었다.
```

### 13-2. 한계점

```text
본 분석은 삼성전자 한 종목의 주가 데이터만을 사용했기 때문에 다른 기업이나 시장 전체의 움직임과 직접 비교하기 어렵다.

또한 주가의 상승과 하락 자체는 확인할 수 있지만, 특정 시점의 주가 변화가 발생한 경제적·기업적 원인까지는 설명하지 못한다. 향후에는 코스피 지수, 기업 실적, 반도체 산업 관련 지표 등의 데이터를 추가하여 주가 변화의 원인을 함께 분석할 필요가 있다.
```
